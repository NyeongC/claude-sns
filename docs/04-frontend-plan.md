# 프론트엔드 화면 설계 계획

## 화면 목록

| 화면 | URL | 접근 조건 |
|------|-----|----------|
| 로그인 | `/login` | 비인증 |
| 회원가입 | `/signup` | 비인증 |
| 메인 피드 | `/` | 인증 필요 |
| 프로필 | `/profile/{username}` | 인증 필요 |

---

## 메인 피드 (`/`)

피드에 표시되는 글(Post) 목록과 글쓰기 폼을 포함한다.

### 레이아웃

```
┌──────────────────────────────────────────┐
│  [로고]                    [로그아웃]     │  ← 헤더
├──────────────────────────────────────────┤
│  ┌────────────────────────────────────┐  │
│  │  글쓰기...                [올리기] │  │  ← 글쓰기 폼
│  └────────────────────────────────────┘  │
│                                          │
│  정렬: [최신순▼]  [인기순]               │  ← 정렬 탭
│  ──────────────────────────────          │
│  ┌────────────────────────────────────┐  │
│  │ @alice  · 3분 전                   │  │
│  │ 오늘 날씨 좋다                     │  │
│  │ ❤ 12  🔁 3  💬 2                  │  │  ← 좋아요 / 리포스트 / 댓글 수
│  └────────────────────────────────────┘  │
│  ┌────────────────────────────────────┐  │
│  │ @bob   · 10분 전                   │  │
│  │ ...                                │  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

### 정렬 옵션

| 옵션 | 기준 | 쿼리 파라미터 |
|------|------|--------------|
| 최신순 | `createdAt DESC` | `?sort=latest` (기본값) |
| 인기순 | `likeCount DESC` | `?sort=popular` |

---

## 글쓰기 기능

- 최대 280자 텍스트 입력
- 등록 시 `POST /api/v1/posts` 호출 → 성공 시 피드 상단에 즉시 반영
- 빈 글 등록 방지 (클라이언트 유효성 검사)

---

## 좋아요 기능

- 피드/댓글의 ❤ 버튼 클릭 시 토글
- 이미 좋아요한 경우 → 취소
- `POST /api/v1/posts/{postId}/likes` / `DELETE /api/v1/posts/{postId}/likes`
- 좋아요 수는 버튼 옆에 실시간 반영

---

## 리포스트 기능

- 🔁 버튼 클릭 시 해당 글을 내 피드에 리포스트
- 이미 리포스트한 경우 → 리포스트 취소
- 리포스트된 글은 원작자 정보와 함께 표시 (`@원작자 글을 리포스트함`)
- `POST /api/v1/posts/{postId}/reposts` / `DELETE /api/v1/posts/{postId}/reposts`

---

## 댓글 기능

- 💬 버튼 클릭 시 댓글 목록 펼침 (인라인 토글)
- 댓글 입력 폼은 목록 하단에 배치
- 댓글은 `createdAt ASC` (오래된 순)으로 표시
- `GET /api/v1/posts/{postId}/comments`
- `POST /api/v1/posts/{postId}/comments`

## 백엔드 API 계획 (프론트 연동 대상)

| 도메인 | 메서드 | URL | 설명 |
|--------|--------|-----|------|
| Post | POST | `/api/v1/posts` | 글 작성 |
| Post | GET | `/api/v1/posts?sort=latest\|popular` | 피드 조회 |
| Like | POST | `/api/v1/posts/{postId}/likes` | 좋아요 |
| Like | DELETE | `/api/v1/posts/{postId}/likes` | 좋아요 취소 |
| Repost | POST | `/api/v1/posts/{postId}/reposts` | 리포스트 |
| Repost | DELETE | `/api/v1/posts/{postId}/reposts` | 리포스트 취소 |
| Comment | GET | `/api/v1/posts/{postId}/comments` | 댓글 목록 |
| Comment | POST | `/api/v1/posts/{postId}/comments` | 댓글 작성 |

---

## 구현 우선순위

1. Post 도메인 (글쓰기 + 피드 조회)
2. 정렬 (최신순 → 인기순)
3. 좋아요
4. 댓글
5. 리포스트
6. 프로필 화면
